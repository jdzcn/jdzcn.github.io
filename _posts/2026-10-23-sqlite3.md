`sqlite3` 最常用的操作指南

### 🚀 启动与退出

启动 SQLite 命令行工具非常简单，在终端输入 `sqlite3` 并跟上数据库文件名即可。

```bash
# 打开或创建一个名为 mydatabase.db 的数据库文件
sqlite3 mydatabase.db

# 启动一个临时的内存数据库（关闭后数据消失）
sqlite3

# 或显式指定内存数据库
sqlite3 :memory:
```
退出命令行工具，可以使用 `.exit` 或 `.quit` 命令。

### 📂 数据库与文件操作

这些命令帮助你管理数据库文件和进行备份恢复。

| 命令 | 说明 | 示例 |
| :--- | :--- | :--- |
| `.open [文件名]` | 打开或切换到另一个数据库 | `.open backup.db` |
| `.backup ?DB? 文件` | 在线备份数据库到指定文件 | `.backup main backup_2023.db` |
| `.restore ?DB? 文件` | 从备份文件恢复数据库 | `.restore main backup_2023.db` |
| `.dump ?表名?` | 导出数据库为 SQL 脚本 | `.dump` (导出全部) |
| `.read 文件名` | 执行一个 SQL 脚本文件 | `.read import_data.sql` |
| `.save 文件名` | 将内存数据库保存到文件 | `.save mem_backup.db` |

### 🔄 数据导入与导出（重点）

这是你最关心的部分，SQLite 对 CSV 格式的支持非常成熟。

#### **导出数据到 CSV**

**方法一：交互式导出（推荐）**
在 `sqlite3` 提示符下，通过一系列点命令完成。

```sql
-- 1. 设置输出模式为 CSV
.mode csv
-- 2. 开启表头输出（可选）
.headers on
-- 3. 将后续查询结果输出到文件
.output users_export.csv
-- 4. 执行查询，结果会写入文件
SELECT * FROM users;
-- 5. 恢复输出到屏幕
.output stdout
```

**方法二：命令行一次性导出（更快捷）**
可以直接在系统终端中，用一条命令完成导出，非常适合脚本自动化。

```bash
# 使用 -header 和 -csv 选项，将查询结果直接重定向到文件
sqlite3 -header -csv mydatabase.db "SELECT * FROM users;" > users_export.csv
```

#### **从 CSV 导入数据**

**前提**：你需要先在数据库中创建好与 CSV 文件列对应的表。

```sql
-- 1. 创建与CSV结构匹配的表（如果尚未创建）
CREATE TABLE users (id INTEGER, name TEXT, email TEXT);
```

**导入命令**：
在 `sqlite3` 提示符下，切换为 CSV 模式后，使用 `.import` 命令。

```sql
.mode csv
.import users.csv users
```
这会将 `users.csv` 文件的数据导入到 `users` 表中。

> **注意**：在新版 SQLite CLI 中，也可以使用 `.import --csv users.csv users` 来实现同样的效果。

### 💾 备份与恢复

除了前面表格中的 `.backup` 和 `.restore` 命令，另一种非常直观的备份方式是利用 `.dump` 命令将数据库导出为 SQL 文本文件，然后通过执行这个文件来恢复。

```bash
# 备份：将整个数据库导出为 SQL 文件
sqlite3 mydatabase.db .dump > backup.sql

# 恢复：通过执行 SQL 文件来重建数据库
sqlite3 new_database.db < backup.sql

#指定表，字段导出insert sql
sqlite3 sales_20261018_101730.db ".headers on" ".mode insert sale" "SELECT date,pid,number,price,amount,cost FROM sale where date>='2026-10-18';" >data.sql

#cloudflare d1导入上面导出生成的insert sql
npx wrangler d1 execute sales-db --local --file=data.sql 

#db文件导入上面生成的insert sql
sqlite3 new_database.db < data.sql
```

### 🎨 输出格式化

在交互模式下，可以使用 `.mode` 命令切换查询结果的显示格式，让输出更易读。

| 模式 (`.mode`) | 效果 |
| :--- | :--- |
| `list` | 默认模式，用竖线 `|` 分隔字段 |
| `csv` | 逗号分隔值格式 |
| `column` | 左对齐的列格式 |
| `box` | 带边框的表格格式 |
| `json` | 输出为 JSON 数组 |
| `markdown` | 输出为 Markdown 表格 |

配合 `.headers on` 可以显示列名，`.width` 可以设置列宽。

### 🔍 元数据查询

这些点命令用于快速查看数据库的结构信息。

| 命令 | 说明 |
| :--- | :--- |
| `.databases` | 列出所有附加的数据库 |
| `.tables` | 列出所有表 |
| `.schema ?表名?` | 显示表的结构（`CREATE` 语句） |
| `.indexes ?表名?` | 列出表的索引 |
| `.fullschema` | 显示完整的数据库结构 |

### ⚙️ 其他实用命令

-   **`.timer on`**：开启后，每次查询会显示耗时，便于性能分析。
-   **`.show`**：显示当前的所有设置。
-   **`.help`**：查看所有点命令的帮助信息。

这些命令构成了 SQLite 命令行工具的核心操作集，覆盖了日常管理和数据交换的大部分场景。
